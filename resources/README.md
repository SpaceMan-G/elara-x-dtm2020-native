# External DTM2020 resource

The operational DTM2020 coefficient resource is **not included**.

This repository intentionally contains no copy of:

- `DTM_2020_F107_Kp`
- `DTM_2020_F107_Kp.dat`
- official SWAMI/CNES DTM Fortran source
- DTM fitted coefficient values.

Authorised users must obtain required DTM assets from an authorised upstream
source and comply with the current upstream licence.

The public resource-boundary code rejects project-local resource placement by
design.
