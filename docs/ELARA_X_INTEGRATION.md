# Elara X integration boundary

The complete Elara X application is not part of this repository.

Within private Elara X, DTM2020 Operational is a first-class selectable model
with accepted bindings to:

- Atmospheric Model Validation Suite (AMVS);
- Combined Model Analysis;
- Combined Atmospheric Heatmap;
- managed GFZ F10.7 / Kp input resolution;
- managed result/provenance workflows.

The final private release was accepted after 64 native cases, 64 official-oracle
cases, 576 comparisons with zero failures, and bounded post-integration
regression.

This public repository exposes only the independently publishable DTM-specific
public-specification closure.
